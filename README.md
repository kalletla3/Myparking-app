\# MyParkingApp Automation



This repository contains Appium + TestNG automation for the MyParkingApp mobile application.



\## Features

\- Add Funds automation

\- Negative \& positive test cases

\- Secure WebView detection

\- API automation (coming soon)

\- Allure reporting

\- Screenshots on failure



\## Tech Stack

\- Java

\- Appium

\- TestNG

\- Maven
